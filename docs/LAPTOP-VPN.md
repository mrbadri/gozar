# راهنمای VPN لپ‌تاپ

با دستور `vpn` لپ‌تاپ از همون راهی به اینترنت آزاد وصل می‌شه که گوشی وصل می‌شه: اول به سرور ایران، بعد به سرور خارج. اپ جدایی نصب نمی‌کنی. `vpn` یه تونل روی خود لپ‌تاپ باز می‌کنه و تنظیمات proxy ِ مک رو روی اون می‌ذاره. از اون به بعد مرورگر و بیشتر اپ‌ها از این تونل رد می‌شن.

لازم نیست همه‌چیز از VPN بره. برای هر سایت خودت تعیین می‌کنی از کدوم راه بره:

| راه | ترافیک از کجا می‌ره |
|---|---|
| `vpn` | تونل ما ← سرور ایران ← سرور خارج ← اینترنت |
| `cisco` | Cisco VPN ِ شرکت (وقتی وصله) |
| `direct` | اینترنت معمولی، بدون تونل ما |

اگه با این راهنما راحت‌تری، `vpn docs` همین متن رو به‌شکل یه صفحهٔ مرتب توی مرورگر باز می‌کنه.

## شروع سریع

**۱. نصب** (روی هر لپ‌تاپ فقط یه بار):

```bash
ln -sf "$PWD/cli/laptop-vpn.sh" ~/.local/bin/vpn   # از پوشهٔ gozar
vpn completion
```

دستور دوم Tab رو برای `vpn` فعال می‌کنه. بعدش یه ترمینال تازه باز کن.

**۲. اولین اتصال.** این رو توی یه ترمینال معمولی بزن، نه توی کادر `!` ِ Claude:

```bash
vpn on
```

بار اول رمز کاربر SSH ِ سرورت رو می‌پرسه و توی Keychain ِ مک نگهش می‌داره. دفعه‌های بعد دیگه نمی‌پرسه. آدرس و کاربر سرور رو اول با `vpn config conn` (یا از راه‌اندازی ِ اپ گذر) بنویس.

**۳. همین.** از این به بعد:

```bash
vpn on      # وصل شو
vpn         # ببین وضعیت چطوره
vpn off     # قطع کن؛ همه‌چیز برمی‌گرده مثل قبل
```

قبل از `vpn on`، Clash یا v2ray یا هر فیلترشکن دیگه‌ای رو خاموش کن. همه‌شون همین تنظیمات proxy ِ مک رو دست می‌زنن و با هم قاطی می‌شن.

## اپ گذر

گذر روی macOS 14 به بالا کار می‌کنه. اگه فایل `Gozar.app` رو آماده داری، بذارش توی Applications، بازش کن و مراحل «راه‌اندازی» رو دنبال کن. خود اپ دستورهای اتصال و Xray رو همراه داره. می‌تونی توی راه‌اندازی انتخاب کنی که دستور `vpn` برای ترمینال هم نصب بشه.

برای ساخت و نصب از پوشهٔ `gozar` با Command Line Tools مک:

```bash
scripts/install.sh
open ~/Applications/Gozar.app
```

برای دیدن ترافیک، توی «تنظیمات» بخش «حالت مسیریاب» رو فعال کن و «ذخیره» رو بزن. اگه VPN وصله، با تنظیم جدید دوباره وصل می‌شه. اگه قطعه، از «نمای کلی» روی «وصل شو» بزن. هر وقت حالت مسیریاب رو خاموش کنی و ذخیره کنی، `vpn` برمی‌گرده به حالت کلاسیک.

| صفحه | چی می‌بینی یا چه کاری می‌کنی |
|---|---|
| نمای کلی | وضعیت VPN، IP خروجی، سرعت هر مسیر و وضعیت راه از مک تا اینترنت. از همین‌جا وصل یا قطعش کن. |
| زنده | اتصال‌ها، مسیر هرکدوم، زمان اتصال و ترافیک. می‌تونی فقط اتصال‌های باز یا خطاها رو ببینی. |
| دامنه‌ها | مصرف و سرعت هر دامنه، میزبان‌های اون و قانونی که مسیرش رو تعیین کرده. |
| قانون‌ها | قانون‌های مسیر رو ببین و ویرایش کن، مسیر یه آدرس رو بررسی کن یا دامنه‌های یه سایت رو پیدا کن. |
| سرورها | افزودن، آزمایش و انتخاب سرورهای SSH و V2Ray و مدیریت اشتراک‌ها. وضعیت سرور خارج و نمودارها با توکن Grafana نمایش داده می‌شن. |
| تنظیمات | تنظیمات محلی اتصال، حالت مسیریاب و توکن Grafana. |

با بستن پنجره، گذر توی نوار منوی مک می‌مونه. از همون‌جا هم می‌تونی وضعیت رو ببینی یا وصل و قطع کنی.

**توکن Grafana برای بخش مانیتورینگ صفحهٔ «سرورها»**

1. توی Grafana از منوی **Administration** وارد **Users and access → Service accounts** شو.
2. روی **Add service account** بزن و با یه اسم مثل `gozar` حساب رو بساز. توی صفحهٔ حساب نقش **Viewer** رو انتخاب کن.
3. روی **Add service account token** بزن، یه اسم برای توکن وارد کن و **Generate token** رو بزن.
4. توکن رو کپی کن، توی «تنظیمات» گذر بذارش و «ذخیره» رو بزن. گذر توکن رو توی Keychain نگه می‌داره.

[راهنمای ساخت توکن در Grafana](https://grafana.com/docs/grafana/latest/administration/service-accounts/#add-a-token-to-a-service-account-in-grafana)

## سرورها و V2Ray

از صفحهٔ «سرورها» می‌تونی یه سرور SSH اضافه کنی، لینک VLESS، VMess، Trojan یا Shadowsocks رو بچسبونی یا آدرس اشتراک رو وارد کنی. از همون‌جا سرورها رو آزمایش کن و یکی رو برای اتصال انتخاب کن. اگه گذر وصله، با انتخاب سرور جدید دوباره وصل می‌شه.

| کار | دستور |
|---|---|
| دیدن شناسه‌ها و سرور فعال | `vpn exits` |
| افزودن لینک V2Ray | `vpn exit add 'LINK' --name NAME` |
| افزودن SSH و وارد کردن رمز در ترمینال | `vpn exit add ssh://user@host:port` |
| انتخاب سرور | `vpn exit use ID` |
| آزمایش زمان اتصال و سرعت دانلود | `vpn exit test ID` یا `vpn exit test --all` |
| تغییر نام یا حذف سرور غیرفعال | `vpn exit rename ID NAME` یا `vpn exit rm ID` |
| افزودن، تازه‌کردن یا حذف اشتراک | `vpn sub add 'URL'`، `vpn sub update [ID]` یا `vpn sub rm ID` |

برای تغییر سرور، شناسه رو از `vpn exits` بردار. رمز SSH توی Keychain ذخیره می‌شه. لینک‌های V2Ray و آدرس اشتراک ممکنه اطلاعات ورود داشته باشن. فایل `~/.config/laptop-vpn/exits.json` و لینک‌ها رو خصوصی نگه دار.

## کارهای روزمره

| می‌خوای… | بزن |
|---|---|
| وصل بشی | `vpn on` |
| قطع کنی | `vpn off` |
| ببینی وصلی یا نه، و IP ِ خروجیت چیه | `vpn` |
| یه سایت رو از VPN بیرون ببری | `vpn set aparat.com direct` |
| یه سایت رو از Cisco بفرستی | `vpn set gitlab.company.example cisco` |
| یه سایت رو برگردونی به VPN | `vpn unset aparat.com` |
| بفهمی یه سایت الان از کجا می‌ره | `vpn check aparat.com` |
| همهٔ دامنه‌های یه سایت رو پیدا کنی | `vpn domains youtube` |
| فایل تنظیمات رو باز کنی | `vpn config` |
| ببینی زنده چی از VPN رد می‌شه | `vpn watch` |
| همین راهنما رو بخونی | `vpn docs` |

هر جا یادت رفت دستور چی بود، `vpn` بزن، یه فاصله، بعد **Tab**. دستورها با توضیح کوتاهشون میان. بعد از `vpn set` یا `vpn check` هم Tab سایت‌هایی رو نشون می‌ده که توی فایلت هستن.

## کدوم سایت از کجا بره

### سه راه

| راه | یعنی |
|---|---|
| `vpn` | از تونل ما. هر سایتی که توی فایل نیست، خودبه‌خود از همین راه می‌ره. |
| `cisco` | وقتی Cisco وصله، از Cisco. وقتی وصل نیست، از جایی که توی `without_cisco` نوشتی. |
| `direct` | هیچ‌وقت از تونل ما نه. |

پس معمولاً فقط سایت‌هایی رو می‌نویسی که **نباید** از VPN برن: سایت‌های ایرانی، دیجی‌کالا، Claude، ابزارهای شرکت.

**یه نکته دربارهٔ Cisco:** وقتی Cisco وصله، کل ترافیک لپ‌تاپ رو خودش می‌گیره و نمی‌ذاره چیزی مستقیم از Wi-Fi بره. این رو تست کردیم و راه دیگه‌ای نیست. پس وقتی Cisco وصله، `direct` هم در عمل از Cisco می‌ره. فرق `cisco` و `direct` فقط وقتی معلوم می‌شه که Cisco وصل نیست:

| | Cisco وصله | Cisco وصل نیست |
|---|---|---|
| `vpn` | تونل ما | تونل ما |
| `cisco` | Cisco | طبق `without_cisco`: اینترنت معمولی (پیش‌فرض) یا تونل ما |
| `direct` | Cisco | اینترنت معمولی |

### فایل `routes.json`

همهٔ این تصمیم‌ها توی یه فایله: `~/.config/laptop-vpn/routes.json`. شکلش این‌طوریه:

```json
{
  "_guide": [ "… راهنمای کوتاه، به فارسی …" ],
  "rules": [
    {
      "name": "Claude",
      "route": "cisco",
      "without_cisco": "vpn",
      "domains": ["claude.ai", "claude.com", "anthropic.com", "claudeusercontent.com"]
    },
    {
      "name": "Iranian sites",
      "route": "direct",
      "domains": ["*.ir", "aparat.com", "torob.com"]
    },
    {
      "name": "Company agents",
      "route": "cisco",
      "hosts": ["corp-mgmt01", "corp-agent-ser"]
    }
  ]
}
```

- `rules` قانون‌های خودته. هر قانون یه گروه سایته با یه راه.
- `_guide` بالای فایل خلاصهٔ همین بخشه، که موقع ویرایش جلوی چشمت باشه. اون رو خود `vpn` به‌روز نگه می‌داره، پس دستش نزن. اگه عوضش کنی، دفعهٔ بعد برمی‌گرده.

### آدرس رو چطوری بنویسم

| می‌نویسی | یعنی |
|---|---|
| `"youtube.com"` | خود `youtube.com` و همهٔ زیردامنه‌هاش (`www.youtube.com`، `m.youtube.com` و بقیه) |
| `"*.company.example"` | **فقط** زیردامنه‌ها (`api.company.example` و بقیه)، نه خود `company.example` |
| `"*.ir"` یا `"ir"` | همهٔ دامنه‌های `.ir` |
| `"https://www.youtube.com/watch?v=x"` | این هم قبوله؛ خودش `youtube.com` رو برمی‌داره |
| توی `hosts`: `"corp-mgmt01"`، `"192.168.1.5"`، `"10.0.0.0/8"` | یه اسم دقیق، یه IP یا یه رنج؛ زیردامنه‌ها رو نمی‌گیره |

### هر قانون چی داره

| کلید | لازمه؟ | چیه |
|---|---|---|
| `name` | بله | یه اسم برای خودت. `vpn routes` و `vpn check` همین رو نشون می‌دن. |
| `route` | بله | `vpn` یا `cisco` یا `direct` |
| `domains` | یکی از این دو | دامنه‌ها، به شکل‌های جدول بالا |
| `hosts` | یکی از این دو | اسم‌های دقیق، IP، رنج |
| `without_cisco` | نه | فقط برای `cisco`: وقتی Cisco وصل نیست کجا بره. `"direct"` (پیش‌فرض) یا `"vpn"` |
| `enabled` | نه | اگه `false` بذاری، قانون خاموش می‌شه ولی پاک نمی‌شه. بدون کوتیشن بنویس. |
| `note` | نه | یادداشت برای خودت. JSON کامنت `//` نداره؛ به‌جاش از این استفاده کن. |

### سه راه برای عوض کردنش

**۱. با `vpn config`** (از همه راحت‌تر):

```bash
vpn config
```

فایل توی VS Code باز می‌شه. عوضش کن، ذخیره کن و **تب رو ببند**. بعدش `vpn` خودش فایل رو چک می‌کنه:

- اگه جایی غلط باشه، دقیق می‌گه کدوم خط و کدوم قانون، و می‌پرسه دوباره بازش کنه یا نه. مثلاً اگه به‌جای `domains` بنویسی `domian`، می‌گه «منظورت `domains` بود؟».
- اگه درست باشه، همون لحظه اعمالش می‌کنه. VPN هم قطع نمی‌شه.

VS Code هم کمکت می‌کنه:

- موقع نوشتن، گزینه‌های درست رو پیشنهاد می‌ده؛ مثلاً برای `route` فقط سه راه بالا رو، با توضیحشون.
- هر جا اشتباه بنویسی، زیرش خط قرمز می‌کشه.
- موس رو روی هر کلید ببری، توضیحش رو نشون می‌ده.
- داخل `"rules": [ … ]` اگه **Ctrl+Space** بزنی، سه قالب آماده برای یه قانون تازه میاد.

اگه ادیتور دیگه‌ای دوست داری: `export EDITOR=nano` (یا `vim`).

**۲. با `vpn set`** برای یه سایت، بدون باز کردن فایل:

```bash
vpn set snapp.taxi direct
vpn set chatgpt.com vpn
vpn set gitlab.company.example cisco
vpn unset snapp.taxi
```

سایت‌هایی که این‌طوری اضافه می‌کنی، توی یه قانون به اسم `Added with vpn set (…)` می‌رن. بعداً اگه خواستی، توی فایل جابه‌جاشون کن.

**۳. دستی**، با هر ادیتوری. مسیر فایل رو `vpn config paths` بهت می‌ده. بعد از ذخیره بزن:

```bash
vpn apply
```

### چند نمونه

| می‌خوای… | قانونش |
|---|---|
| یه سایت ایرانی یا بانک بدون VPN باز بشه | `"route": "direct"` |
| یه سایت شرکت از Cisco بره | `"route": "cisco"` |
| مثل Claude: با Cisco از Cisco، بدون Cisco از VPN (چون Claude IP ِ ایران رو قبول نمی‌کنه) | `"route": "cisco", "without_cisco": "vpn"` |
| فقط زیردامنه‌های یه سایت، نه خودش | `"domains": ["*.example.com"]` |
| یه ایجنت شرکت که اسم ساده داره (توی `vpn watch` با `✗` دیده می‌شه) | `"route": "cisco", "hosts": ["اسمش"]` |
| یه قانون رو یه مدت خاموش کنی | `"enabled": false` |
| همهٔ دامنه‌های یه سایت رو یه‌جا اضافه کنی | `vpn domains youtube --add vpn` (بخش بعد) |

### چند نکتهٔ ریز

- **اگه یه سایت توی دو قانون بود:** اسم دقیق (`hosts`) برنده‌ست. بین دامنه‌ها هم دقیق‌ترین، یعنی طولانی‌ترین، برنده می‌شه. `vpn check` دقیقاً می‌گه کدوم قانون اعمال شده.
- **یه محدودیت مک:** تنظیمات proxy ِ مک فقط می‌تونه بگه «این‌ها از proxy نرن». پس اگه یه دامنه `direct` یا `cisco` باشه، نمی‌شه یه زیردامنه‌ش رو دوباره `vpn` کرد. مثلاً اگه همهٔ `.ir`ها مستقیم باشن، `example.ir` رو نمی‌شه از VPN فرستاد. `vpn routes` اگه همچین چیزی ببینه بهت می‌گه.
- **همیشه مستقیم:** خود لپ‌تاپ و شبکهٔ داخلی (`localhost`، `*.local`، `10.*`، `172.16.*` تا `172.31.*`، `192.168.*` و اسم‌های ساده) هیچ‌وقت از VPN نمی‌رن. این‌ها توی فایل نیستن و عوض‌شدنی هم نیستن.

## پیدا کردن دامنه‌های یه سایت

یه سایت معمولاً فقط یه دامنه نیست. یوتیوب مثلاً ویدیو رو از `googlevideo.com` می‌ده و عکس‌ها رو از `ytimg.com`. اگه فقط `youtube.com` رو بنویسی، بقیه‌ش از راه دیگه‌ای می‌ره. این دستور همه‌شون رو برات پیدا می‌کنه:

```bash
vpn domains youtube
```

از دو جا می‌گرده:

- **یه لیست عمومی** (v2fly geosite). اپ‌های VPN این لیست رو برای سرویس‌های معروف نگه می‌دارن: یوتیوب، تلگرام، گوگل، گیت‌هاب، نتفلیکس، OpenAI و خیلی‌های دیگه. دقیقه، ولی فقط سرویس‌های معروف رو داره. نسخه‌های کشوری مثل `youtube.de` رو کنار می‌ذاره.
- **خود سایت.** سایت رو حدود ۱۵ ثانیه توی یه Chrome ِ بی‌صفحه باز می‌کنه و هر دامنه‌ای که صفحه بهش وصل شد رو یادداشت می‌کنه. برای هر سایتی کار می‌کنه، حتی دیجی‌کالا که توی لیست عمومی نیست.

کنار هر دامنه می‌نویسه **الان** از کجا می‌ره. دامنه‌هایی که بین خیلی از سایت‌ها مشترکن (مثل `google.com`، `gstatic.com` یا `cloudfront.net`) علامت `[shared]` می‌خورن و خودبه‌خود اضافه نمی‌شن، چون اگه جابه‌جاشون کنی خیلی سایت‌های دیگه هم باهاشون جابه‌جا می‌شن. آخر خروجی هم یه لیست آماده می‌ده که می‌تونی توی فایل کپی کنی.

برای اینکه مستقیم اضافه‌شون کنه:

```bash
vpn domains youtube --add vpn
vpn domains company.example --add cisco --name Company
vpn domains telegram --add direct --all
vpn domains github.com --quick
```

- `--add` دامنه‌ها رو با اون راه اضافه می‌کنه. اگه قانونی به اسم اون سایت باشه، بهش اضافه می‌کنه؛ اگه نباشه، می‌سازدش.
- `--name` اسم قانون رو خودت انتخاب می‌کنی.
- `--all` هرچی Chrome بیشتر دیده رو هم اضافه می‌کنه، حتی دامنه‌های مشترک رو.
- `--quick` فقط لیست عمومی رو نگاه می‌کنه و Chrome رو باز نمی‌کنه.
- اسم سایت رو هر جوری بدی قبوله: `youtube`، `youtube.com` یا آدرس کامل. اگه آدرس `?` یا `&` داره، توی کوتیشن بذارش، وگرنه zsh خطای `no matches found` می‌ده:
  ```bash
  vpn check 'https://www.youtube.com/watch?v=x'
  ```
- اگه VPN روشن باشه، همه‌چیز از VPN دانلود و باز می‌شه، پس سایت‌های فیلترشده هم کار می‌کنن.

## وقتی Cisco وصله

- **تونل ما هم از داخل Cisco رد می‌شه.** Cisco اجازه نمی‌ده دورش بزنیم. سرعتش حدود ۱٫۳ مگابایت بر ثانیه‌ست که برای یوتیوب کافیه.
- **رمز مک رو می‌پرسه.** وقتی Cisco وصله، مک تنظیمات proxy رو از یه کپی می‌خونه که خود Cisco لحظهٔ وصل شدن برداشته و دیگه به‌روزش نمی‌کنه. برای همین `vpn on`، `vpn off`، `vpn apply`، `vpn set`، `vpn unset` و `vpn domains --add` اون کپی رو هم درست می‌کنن و برای این کار رمز مک لازم دارن. رمز رو ۵ دقیقه یادش می‌مونه. این دستورها رو وقتی Cisco وصله توی ترمینال بزن، نه توی کادر `!` ِ Claude که نمی‌تونه رمز بپرسه.
- **Cisco رو بعد از `vpn on` وصل یا قطع کردی؟** `vpn` بهت می‌گه `run: vpn apply`. همون رو بزن تا سایت‌های `cisco` از راه درست برن.
- **یوتیوب با Cisco باز نمی‌شه؟** `vpn` رو بزن. اگه نوشته `its proxy copy: off`، یعنی کپی ِ Cisco درست نشده. `vpn apply` رو توی ترمینال بزن.
- **بعد از `vpn off` با Cisco هیچ سایتی باز نمی‌شه؟** احتمالاً `vpn off` بدون رمز اجرا شده و کپی ِ Cisco هنوز به تونل بسته اشاره می‌کنه. `vpn off` رو توی ترمینال بزن، یا Cisco رو یه بار قطع و وصل کن.

## تنظیمات اتصال: `connection.json`

اینکه `vpn` به کجا و چطوری وصل بشه، توی `~/.config/laptop-vpn/connection.json` هست. معمولاً دستش نمی‌زنی، مگه اینکه چیزی روی سرور عوض شده باشه.

```json
{
  "relay": { "host": "203.0.113.10", "port": 47853, "user": "vpnuser" },
  "local_socks_port": 1080,
  "keepalive": { "interval_seconds": 5, "max_missed": 3 },
  "connect_timeout_seconds": 15,
  "reconnect_delay_seconds": 3,
  "ciphers": ["aes128-gcm@openssh.com", "chacha20-poly1305@openssh.com"]
}
```

| کلید | چیه | کی عوضش کنی |
|---|---|---|
| `relay.host` | آدرس سرور ایران | اگه سرور ایران عوض شد |
| `relay.port` | پورت تونل روی سرور ایران | اگه پورت رو روی سرور عوض کردی |
| `relay.user` | اسم کاربری | تقریباً هیچ‌وقت |
| `local_socks_port` | پورتی که تونل روی خود لپ‌تاپ باز می‌کنه | اگه `vpn on` گفت پورت ۱۰۸۰ دست یه برنامهٔ دیگه‌ست |
| `keepalive` | هر چند ثانیه چک کنه و بعد از چند بار بی‌جواب، قطع و وصل کنه. الان ۵ ثانیه × ۳ بار، یعنی ۱۵ ثانیه. | اگه خیلی قطع و وصل می‌شه، بزرگ‌ترش کن |
| `connect_timeout_seconds` | چقدر برای وصل شدن صبر کنه | معمولاً نه |
| `reconnect_delay_seconds` | بعد از قطع شدن، چقدر صبر کنه تا دوباره وصل بشه | معمولاً نه |
| `ciphers` | نوع رمزنگاری | معمولاً نه |

رمز توی این فایل نیست. رمز توی Keychain ِ مکه و `vpn forget` پاکش می‌کنه. برای ویرایش، `vpn config conn` بزن. اگه وصل باشی، بعد از ذخیره یه بار قطع و وصل می‌شه که چند ثانیه طول می‌کشه.

## از کجا بفهمم چی از کجا می‌ره

- **`vpn`** وضعیت رو می‌گه: تونل روشنه یا نه، IP ِ خروجی (باید IP ِ سرور خارج باشه، نه اینترنت خودت)، proxy ِ سیستم و Cisco. اگه کاری لازم باشه، مثل `vpn apply`، همین‌جا می‌گه.
- **`vpn check aparat.com`** می‌گه یه سایت الان از کجا می‌ره و طبق کدوم قانون:
  ```
  claude.ai → cisco  (rule "Claude", matches claude.ai)
  claude.ai → vpn    (rule "Claude", matches claude.ai)  [rule says cisco; Cisco is not connected]
  ```
- **`vpn routes`** همهٔ قانون‌ها رو نشون می‌ده و اینکه هر کدوم همین الان از کجا می‌ره.
- **`vpn watch`** زنده نشون می‌ده چی داره از VPN رد می‌شه. یه ترمینال جدا باز کن و بزن:
  ```
  15:50:49 → www.youtube.com:443      یه اتصال تازه از VPN
  15:50:41 ✗ connect failed: …          سرور خارج نتونست به اون سایت برسه
  --- 2026-11-09 21:35:01 connecting    تونل قطع شده بود و خودش دوباره وصل شد
  ```
  سایتی که باز می‌شه ولی اینجا نمیاد، از VPN نرفته. با `Ctrl+C` بیا بیرون؛ VPN قطع نمی‌شه. فقط اسم سایت‌ها ثبت می‌شه، نه محتوای صفحه‌ها. HTTPS رمزشده‌ست و قرار هم نیست دیده بشه.
- **`vpn top`** سایت‌هایی رو نشون می‌ده که بیشتر از همه از VPN رد شدن. جای خوبیه برای پیدا کردن چیزهایی که باید `cisco` یا `direct` بشن. اسم‌های ساده‌ای که با `✗` میان، معمولاً ایجنت‌های شرکتن.

## چیزهایی که این VPN نمی‌تونه

- **همهٔ برنامه‌ها از proxy ِ مک استفاده نمی‌کنن.** Safari، Chrome، تلگرام دسکتاپ و بیشتر اپ‌های مک استفاده می‌کنن. ابزارهای ترمینال مثل `curl`، `git`، `pnpm`، `pip` و `docker` استفاده نمی‌کنن. اگه می‌خوای این‌ها هم از VPN برن، توی همون ترمینال بزن:
  ```bash
  export ALL_PROXY=socks5h://127.0.0.1:1080
  ```
  Firefox اگه روی «Use system proxy settings» باشه از VPN می‌ره.
- **فقط TCP رد می‌شه.** مرورگرها خودشون با این کنار میان، ولی بعضی تماس‌های صوتی و تصویری ممکنه وصل نشن.
- **سرعت** یه اتصال حدود ۱٫۳ تا ۱٫۵ مگابایت بر ثانیه‌ست (اندازه‌گیری آبان ۱۴۰۵). محدودیتش از مسیر سرور ایران به سرور خارجه، نه از لپ‌تاپ.
- **وقتی راه سرور ایران به خارج قطعه،** این VPN هم قطعه. تونل خودش مدام تلاش می‌کنه و وقتی راه باز شد، دوباره وصل می‌شه.

## اگه کار نکرد

| مشکل | چیکار کنی |
|---|---|
| هیچ سایتی باز نمی‌شه | `vpn` بزن. اگه تونل `down` بود، `vpn off` و بعد `vpn on`. اگه باز هم نشد، راه سرور ایران به خارج قطعه؛ بخش Troubleshooting توی `PHONE-VPN.md` رو ببین. |
| یوتیوب با Cisco باز نمی‌شه | `vpn` بزن. اگه `its proxy copy: off` یا `run: vpn apply` نوشته بود، `vpn apply` رو توی ترمینال بزن. |
| `config error: …` | پیام می‌گه کدوم فایل و کدوم خط یا قانون. رایج‌ترین اشتباه‌ها: کاما بعد از آخرین مورد لیست، کوتیشن تکی به‌جای جفت، کامنت `//`، یا `route` ِ غلط. `vpn config` دوباره بازش می‌کنه. |
| `no password saved yet` | `vpn on` رو یه بار توی ترمینال معمولی بزن؛ کادر `!` نمی‌تونه رمز بپرسه. |
| `STOPPED: wrong password` | `vpn forget` و بعد `vpn on` با رمز درست |
| `STOPPED: host key changed` | سرور خارج عوض شده. `vpn reset-hostkey` و بعد `vpn on` |
| یه سایت ایرانی یا سایت شرکت باز نمی‌شه | `vpn check <سایت>`. اگه گفت `vpn`، بزن `vpn set <سایت> direct` (یا `cisco`). |
| `vpn on` می‌گه پورت گرفته‌ست | یه برنامهٔ دیگه روی ۱۰۸۰ نشسته. ببندش، یا `local_socks_port` رو با `vpn config conn` عوض کن. |
| بعد از `vpn off` proxy خاموش نشد | `vpn off` رو دوباره بزن. تنظیمات قبلی هر کارت شبکه توی `~/.config/laptop-vpn/proxy-before` ذخیره‌ست و `vpn off` همونا رو برمی‌گردونه. |
| Tab کار نمی‌کنه | `vpn completion` بزن و یه ترمینال تازه باز کن. |
| می‌خوام همه‌چیز برگرده به حالت اول | `routes.json` یا `connection.json` رو پاک کن. دستور بعدی از روی پیش‌فرض‌ها دوباره می‌سازدش. |

## همهٔ دستورها

| دستور | کارش |
|---|---|
| `vpn on` | وصل می‌شه و proxy ِ مک رو روشن می‌کنه. اگه قطع بشه، خودش دوباره وصل می‌شه. |
| `vpn off` | proxy ِ هر کارت شبکه رو به حالت قبل برمی‌گردونه و قطع می‌کنه. |
| `vpn` | وضعیت |
| `vpn config` | `routes.json` رو باز می‌کنه؛ بعد از بستن، چکش می‌کنه و اعمالش می‌کنه. |
| `vpn config conn` | همین برای `connection.json` |
| `vpn config paths` | مسیر فایل‌ها |
| `vpn apply` | فایل‌ها رو چک و اعمال می‌کنه: بعد از ویرایش دستی، یا وقتی Cisco وصل یا قطع شد. |
| `vpn routes` | همهٔ قانون‌ها و اینکه هر کدوم الان از کجا می‌ره |
| `vpn set <سایت>… vpn\|cisco\|direct` | سایت رو همون لحظه به اون راه می‌فرسته و توی فایل ذخیره می‌کنه. |
| `vpn unset <سایت>…` | سایت رو از همهٔ قانون‌ها برمی‌داره؛ یعنی از VPN می‌ره. |
| `vpn check <سایت>` | سایت الان از کجا می‌ره و طبق کدوم قانون |
| `vpn domains <سایت>` | همهٔ دامنه‌های یه سایت؛ با `--add` اضافه‌شون می‌کنه. |
| `vpn watch` | زنده: چی از VPN رد می‌شه |
| `vpn top` | سایت‌هایی که بیشتر از همه از VPN رفتن |
| `vpn docs` | همین راهنما، توی مرورگر (`vpn docs md`: خود فایل توی VS Code) |
| `vpn completion` | Tab رو برای `vpn` فعال می‌کنه. |
| `vpn help` | خلاصهٔ همهٔ دستورها توی خود ترمینال |
| `vpn try <IP>` | برای تست یه سرور خروجی تازه. برگشت به حالت عادی: `vpn on` |
| `vpn reset-hostkey` | بعد از اینکه سرور خارج عوض شد |
| `vpn forget` | رمز رو از Keychain پاک می‌کنه. |
| `vpn add` / `vpn rm` | اسم‌های قدیمی؛ یعنی `vpn set <سایت> direct` و `vpn unset` |

## فایل‌ها کجان

| کجا | چیه |
|---|---|
| `~/.config/laptop-vpn/routes.json` | **قانون‌های خودت** |
| `~/.config/laptop-vpn/connection.json` | **تنظیمات اتصال خودت** |
| `~/.config/laptop-vpn/ssh.log` | گزارش تونل؛ `vpn watch` همین رو نشون می‌ده. بالای ۲۰ مگابایت خودش خالی می‌شه. |
| `~/.config/laptop-vpn/proxy-before` | تنظیمات proxy قبل از `vpn on`، که `vpn off` برمی‌گردونه |
| Keychain ِ مک، سرویس `vpnuser-relay` | رمز `vpnuser` |
| `cli/laptop-vpn.sh` (توی repo ِ gozar) | خود دستور `vpn`؛ `~/.local/bin/vpn` بهش لینک شده |
| `cli/laptop-vpn.d/` | پیش‌فرض‌ها، schema ِ VS Code، `vpnconf.py` (خوندن و چک فایل‌ها)، `sitedomains.py` (`vpn domains`)، `docs.py` (`vpn docs`)، `_vpn` (Tab) |

سمت سرورها، یعنی سرور ایران، سرور خارج و عیب‌یابی اون‌ها، توی [`PHONE-VPN.md`](PHONE-VPN.md) نوشته شده.
